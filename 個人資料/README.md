# 個人資料夾說明

這個資料夾用來集中存放個人相關資料，每個主題各自獨立成一份文件，方便日後統一分析。

## 目前規劃的文件

| 檔案 | 內容 | 格式 |
|---|---|---|
| `天干地支.md` | 生辰八字（年月日時干支）、五行分析 | Markdown |
| `星座命盤.md` | 出生資訊、太陽/月亮/上升星座、行星宮位 | Markdown |
| `紫微斗數.md` | 十二宮位主星、四化、大限流年 | Markdown |
| `生命靈數.md` | 生命靈數、天賦數、數字九宮格分布 | Markdown |
| `人類圖.md` | 類型、策略、內在權威、九大能量中心、通道閘門 | Markdown |
| `瑪雅十三月亮曆.md` | KIN值、調性、太陽圖騰、四大力量 | Markdown |
| `個人經歷.md` | 學經歷、重要人生事件時間軸 | Markdown |

## 使用方式

1. 請直接編輯對應的 `.md` 檔案，把佔位內容換成實際資料；或是把資料貼給我，我幫你整理進檔案。
2. 紫微斗數是圖檔，麻煩直接把命盤截圖或照片拖進這個資料夾，檔名建議維持 `紫微斗數.png`（或副檔名依實際圖檔調整）。
3. 之後若還有其他主題（例如塔羅牌解讀、MBTI 測驗結果等），可以比照格式新增檔案，並回來更新這份說明。
4. 所有資料備齊後，跟我說一聲，我會統整所有文件進行綜合分析。
