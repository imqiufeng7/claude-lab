# 劉靖瑩 | 平面設計作品集 Landing Page

自由接案平面設計師劉靖瑩（Jing Ying Liu）的個人形象網站，以單頁式 Landing Page 呈現品牌介紹、精選作品與聯絡方式。

## 功能

- **Hero 區塊**：品牌標語、簡介與雙 CTA 按鈕（聯絡我 / 觀看作品）
- **精選作品區**：三張作品卡片，展示品牌識別、包裝設計、活動視覺三種類型的案例
- **聯絡區塊**：導引訪客以 Email 直接聯繫
- **視覺風格**：深色星空漸層背景、星點與光暈動畫、卡片進場淡入動效
- **RWD 響應式設計**：針對平板（≤860px）與手機（≤480px，含 375px 寬度）優化版面，作品卡片自動改為單欄排列、按鈕符合 44px 觸控最小尺寸、標題字級依螢幕寬度縮放，並確保無元素超出螢幕寬度（overflow-x: hidden）

## 使用技術

- **HTML5**：語意化標籤與結構
- **CSS3**：Flexbox、CSS Grid、CSS 變數（Custom Properties）、`clamp()` 響應式字級、關鍵影格動畫（`@keyframes`）、Media Query 響應式設計
- **Google Fonts**：Inter 字體
- 純前端靜態網頁，無需任何建置工具或後端服務

## 如何在瀏覽器開啟

1. 下載或 clone 本專案
2. 直接用瀏覽器開啟 `index.html`（可雙擊檔案，或在瀏覽器中使用「開啟檔案」）
3. 或使用終端機進入專案資料夾後執行：

   ```bash
   open index.html        # macOS
   # 或啟動本機伺服器預覽
   python3 -m http.server 8000
   ```

   啟動本機伺服器後，於瀏覽器輸入 `http://localhost:8000` 即可預覽。

無需安裝任何相依套件，開啟即可瀏覽。
